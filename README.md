# iCohabit API

This is the backend/API of my iCohabit project. This was built as a house organisation tool for households - particularly focusing on new students.

Frontend/Mobile App [HERE](https://github.com/JakeButterfield99/icohabit-mobile)

## Features

- Add members to your 'household'
- Shared tasks/chores list
- Shard pinboard/notes
- Shared grocery list & meal ideas

## Technologies

- Laravel
- PHP
- MySQL
